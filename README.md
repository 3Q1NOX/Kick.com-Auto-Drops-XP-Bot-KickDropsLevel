🇬🇧 English
Kick Drops & Level
A streamlined Kick extension — focused solely on Drops farming and Level botting.

All extra features (adblock, chat tools, multistream, mod logs, theater mode, recorder, etc.) have been removed.

Features
Drops Farm: Select active campaigns, automatic channel switching, progress HUD, and automatic reward claiming.

Level Bot: Stream watching for leveling, anti-stuck protection, and active tab keep-alive.

Installation
Download this repository and extract the folder.

Go to chrome://extensions in your browser and enable Developer mode.

Click Load unpacked and select the extracted folder.

Usage
Click the DL button at the bottom right of the Kick page to open the panel.

Use the extension popup icon for quick toggle (on/off).

Manage campaign selections directly from the main panel.
