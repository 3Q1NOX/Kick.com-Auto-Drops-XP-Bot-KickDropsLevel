### ⚙️ Detailed Extension Features

#### 🎁 1. Drops Farm System
* **Active Campaign Management:** Lists active Kick Drop campaigns dynamically and lets you choose which ones to track.
* **Smart Auto-Switch:** Automatically switches to another channel with active Drops if the current stream ends or completes its progress.
* **Live Progress HUD:** Displays real-time Drop percentage, remaining time, and status overlay right on the stream page.
* **Auto-Claim Rewards:** Automatically claims earned Drop rewards in the background as soon as they become available.

#### 📈 2. Level Bot & Automated XP Gain
* **Active Tab Keep-Alive:** Prevents Kick from pausing streams when the tab is running in the background or minimized, ensuring uninterrupted watch time.
* **Anti-Stuck Protection:** Automatically detects buffer loops, black screens, or stream freezes and reloads/resumes playback.
* **Resource Optimization:** Keeps CPU and RAM usage extremely low while maintaining full leveling functionality.

#### 🎛️ 3. Interface & Controls
* **On-Page DL Panel:** Access the quick control overlay by clicking the **DL** button located at the bottom right of Kick.com.
* **Quick Extension Popup:** Toggle extension modules on/off instantly via the browser toolbar icon popup.
